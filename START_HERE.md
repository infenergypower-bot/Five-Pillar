# Northstar Endpoint Lab — MD-102 Academy v4

Live site deployment path: `intune-md102-academy.pages.dev` (GitHub Pages integration, production branch `intune-md102-training-deploy`).

To run independently, serve these files together over HTTPS:
- `index.html`
- `v4-style.css`
- `objectives-data.js`
- `v4-core.js`
- `v4-learning.js`
- `scenario-questions.js`
- `supplemental-drills.js`
- `v4-exam.js`

The app is entirely local-browser simulation. It does not enroll actual Microsoft Intune devices or run PowerShell.

Start in Training Academy > Objective coverage, choose an official MD-102 objective, then Guided/independent Practice workshop. Use the three learning modes and five controls. For question practice select Advanced exams. Preserve browser data via the original Export progress function before resetting or switching browsers.

Read `UPGRADE_AUDIT.md` for what is done, tested, and still missing. Avoid treating easy recall drills as a certification-quality 400-item question bank.
